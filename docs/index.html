✨ Overview

Gradient Descent Viz visualizes popular gradient descent methods in machine learning, including vanilla gradient descent, momentum, AdaGrad, RMSProp, and Adam. By playing around with different settings, anyone—beginner or expert—can gain new intuitive understanding of these methods.

🎨 Features

Different Surfaces

Choose between different surfaces to visualize how each algorithm handles various scenarios. For example, see how Adam and RMSProp handle saddle points much better than simple gradient descent or momentum.

Parameter Tuning

Tune parameters to see their effects in real-time. Right-click and drag to rotate, use arrow keys to navigate, and Ctrl (or Cmd) + plus/minus to zoom. Experiment with learning rates and see how they affect the optimization process.

Step-by-Step Animation

Watch step-by-step cartoons to visualize the calculation process of each method. Understand the inner workings of momentum descent and other algorithms.

Visual Elements

Track gradients, momentum, sum of squared gradients, adjusted gradients, and paths. Use visual elements to understand what makes each method work under different circumstances.

Path Drawing

Draw the path of descents to see how different methods reach their destination in different ways.

🛠️ Building from Source

This is a C++ app written in Qt, using the free Qt open-source licensed version. It works cross-platform.

Prerequisites

  • Qt 5.10 or above (download here)
  • Qt Data Visualization package (include in your Qt installation)

Build Steps

  1. Clone this repository
  2. Open gradient_descent_visualization.pro in Qt Creator IDE
  3. Build and run the project

🏗️ Code Structure

  • window class: Responsible for UI layout, including all widgets (spinbox, input text box, etc.) on the sidebar
  • plot_area class: Responsible for actions inside the plot region, including methods responding to user inputs
  • animation class: Controls the logic for animation. Each descent method has its own derived animation class
  • item class: Custom 3D items such as arrows, squares, and paths
  • GradientDescent class: Mathematical implementations of each descent method
